# M3 首次实机准备：用户操作

开发者已准备项目 `.local/minecraft-instance` 独立实例、两个 Mod JAR，以及新启动版本 `fabric-loader-0.19.5-26.3`。没有修改已有启动配置，也没有自动创建世界或启动游戏。

## 现在需要你操作

1. 打开 Minecraft Launcher，选择 **Minecraft: Java Edition → 安装配置 → 新建安装配置**。
2. 名称填 `Bannerlord M3 Test`；版本选择 `fabric-loader-0.19.5-26.3`。
   如果列表找不到，确认安装配置中的“已修改/Modded”筛选已启用，关闭并重新打开启动器。
3. **游戏目录**设为本项目 `.local/minecraft-instance` 的绝对路径。不要留空，不要选普通 `.minecraft`。
4. 展开“更多选项”，保留原有 JVM 参数，并在末尾追加：

   ```text
   -Dbannerlord.bridge.enabled=true
   ```

   Java 可执行文件保持自动选择（26.3 需要 Java 25）；不要指定系统 JDK 17。
5. 保存并启动这个配置。若启动失败，把报错发给开发者，不要切换到普通配置或修改其他 Mod。
6. 进入“单人游戏”，创建名为 **M3-Test** 的新世界，选择**创造模式**并**允许命令**。可使用超平坦世界加快准备；主世界不是桥接建造区。
7. 进入世界后停留几秒，**保存并退出世界，再关闭 Minecraft 和启动器**。
8. 告诉开发者“测试世界已创建，游戏已关闭”。

此时没有授权标记，桥接应保持关闭；日志中出现授权标记缺失提示属于预期保护，不代表 Mod 加载失败。
开发者会检查该独立实例日志与世界目录，然后只为这个测试世界写入标记。
**本轮不要启动 Bannerlord，也不要使用普通存档测试。**
