# 宿主建造操作、回归测试与诊断

本清单用于宿主建造功能回归，保留已实测物理激活流程，不使用战役存档。无桥接配置的 M1 本地模式不依赖 Minecraft；M2/M3-A 已接入可选权威桥接，各模式准备及验收结果见 `M2.md`、`M3.md`。当前宿主 revision 10，不再处于 revision 9 预览待验证阶段。

## 操作

| 按键 | 功能 |
|---|---|
| Ins | 8 米眼部视线内瞄准地面放置，或沿已有方块命中面扩建 |
| Ctrl + Ins | 开关放置预览（默认开启） |
| PgUp | 原生射线选择；成功时黄色轮廓高亮 |
| Del | 删除选中块；未选中时提示操作方法 |
| PgDown | 清空，移除高亮 |
| Ctrl + PgUp | 显示测试编号、数量、Agent 数、拒绝次数；写入完整状态与选中块物理日志，不更改选择 |

M1 按用户要求取消数量上限，不再显示 `/100`。无数量限制不代表无限性能：目前一块一实体，检查为线性扫描，大量生成仍可能卡顿。M2/M3 有各自的传输/观察位置预算和 M3 区域限制，见对应文档。Ctrl+PgUp 可查看诊断，桥接模式还显示同步状态；未同步或等待确认时禁止修改。

## 放置预览回归

预览使用半透明模型配绿色/红色轮廓：绿表示校验通过，红表示存在有效目标但空间冲突、越界或低于地面；桥接未就绪也不允许放置。天空、超距、原版场景物体等无法形成支持目标时隐藏。用户已确认预览整体效果；颜色细分、开关等未逐项验收，仍作为回归步骤。选中方块使用黄色轮廓。

预览使用独立实体，显式 `createPhysics=false`、关闭物理、禁止射线命中，不计入方块数量，不建立 Z 基准。若检测到预览意外存在物理刚体，停止预览并清理，不影响实际建造。约每 0.05 秒更新一次，不每帧创建实体，不在自动预览中刷屏或累计放置拒绝。

历史上 revision 8 预览 prefab 保留物理体导致安全检查禁用，实测不可见。revision 9 改为空实体仅挂载 editor_cube 视觉副本，不加载 prefab 物理；该修复已由用户反馈和无物理体/可见日志验证。

1. 看向地面、顶部与侧面，观察预览位置；按 Ins 后实际方块应出现在相同位置。
2. 目标与角色/马匹或已有方块冲突时应红色，按 Ins 仍拒绝。看向天空、超距目标时预览应隐藏。
3. Ctrl+Ins 关闭/开启，不应同时生成方块；切换后实际放置正常。
4. 预览不阻挡走动、投掷物及 PgUp 选择；清空、离场后预览实体清理（开启状态下清空后允许重新显示当前目标预览）。

预览有更新间隔，移动角色时可能略滞后；Ins 每次重新计算校验，不盲信上次绿灯。预览是可选功能，异常时仅关闭预览。仍只有既有的角色/方块空间校验，绿灯不等于对所有原版物体的完整重叠查询。

## 建造操作复核

1. 空旷平地看向附近地面按 Ins，应在瞄准位置附近的 X/Y 网格生成，而不是固定前方三米。
2. 瞄准方块顶部按 Ins，应叠高；瞄准侧面应横向扩建。底面低于地面时拒绝。棱角命中可能按固定轴优先级选择一个邻面。
3. 看向天空或超过 8 米的地面，提示未命中；瞄准原版建筑/场景物体应拒绝。当前不支持向任意原版表面贴块。
4. PgUp/Del 复查选中删除；同位置重叠及角色/马匹空间保护保留。

角色眼部视线不等于第三人称屏幕中心；建议第一人称测试精确瞄准。首次成功放置的地面高度成为本场景 Z 网格基准；后续地面高度向上取整到整米层，避免任意小幅错层。斜坡上可能出现整块台阶或悬空，并非自动平整地形。清空方块不重置网格，离场后新场景重新建立。地面查询排除实体碰撞，已有方块不会抬高地面层；用户已确认对齐视觉正常。未实现任意宿主关键物体的完整空间查询；只在空旷测试区操作。

用户已确认核心碰撞、AI 和骑乘表现；瞄准放置、网格对齐及预览后续也已接受。revision 5 有 4 次正常退出、最高 34 块日志证据，后续 revision 和桥接另有正常进出记录；用户当时跳过计划第 5 次与 50/100 块压力测试，不能将后续少量测试视为压力项通过。M1 数量上限测试不再适用，桥接预算单独验收。此处步骤用于后续回归，不要求重复所有已接受项目。

## 诊断解释

日志：`%LOCALAPPDATA%\BannerlordBlocks\prototype.log`。

```powershell
pwsh -File tools/ReadDiagnostics.ps1 -Tail 100
dotnet run --project tests/Diagnostics/Diagnostics.csproj -c Release
```

每场独立 session ID；每 10 秒有效 Battle tick 时间写一次 Sample，Ctrl+PgUp 写 Manual status，离场写一次 Test end；重复清理回调不会重复汇总。

- created/deleted：成功创建/删除累计，deleted 包括清空及退出清理。
- rejected/selected/errors：放置拒绝/选择成功/异常次数；errors 包括可选高亮错误。
- peak：场景最大成功方块数。
- meanTickMs/maxTickMs：本场景累计 Mission tick dt 的均值与最大值，不是渲染帧时间、GPU 耗时或模组自身耗时。暂停/加载不采样，忽略非有限或非正 dt。
- managedMiB：`GC.GetTotalMemory(false)`，只代表托管内存估计，不是整个游戏内存；不强制 GC。

物理功能需用户观察；诊断计数不自动把站立、投掷物、AI 或骑乘标记为通过。
